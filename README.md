# Code-for-MDP-projet-on-Hydrovalleys
This project contains the python files, slides and report made for a projet on Hydrovalleys in the MDP class of Ms. Akian.
The files can be executed without any data files because it is a simulation and not an optimization programm on real-life data. 
One should probably execute "dadp_hydro.py" first, then "test_dadp" and then the two other files to generate graphs and results ("Experiments.py" and "plots.py")
